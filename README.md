# 📍 Map Distance App

A simple Android application built using Android Studio that calculates the distance between two locations on a map.

## ✨ Features

- 🗺️ Google Maps Integration
- 📌 Select two locations
- 📏 Calculate distance between points
- 📍 Real-time map interaction
- 📱 User-friendly interface

---

## 🛠️ Built With

- Java / Kotlin
- Android Studio
- Google Maps API
- XML Layouts

---

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

- Android Studio installed
- Google Maps API Key
- Android SDK
